# Security

Please do not report security problems in public issues.

Report them privately through [GitHub security advisories](https://github.com/teransarathchandra/snapr/security/advisories/new). Include what you found, how to reproduce it and the Snapr version. You will get a reply within a week.

Only the [latest release](https://github.com/teransarathchandra/snapr/releases/latest) receives fixes.
